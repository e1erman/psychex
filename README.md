# psychex

**psychex** is a desktop application for Windows that lets you download, manage and run Roblox executors — in a VM. The VM spins up automatically in the background, giving you an extra protection layer against malware without any manual setup.

Built with [Tauri v2](https://tauri.app/) and the [Obsidian](https://mspaint.cc) UI library.
